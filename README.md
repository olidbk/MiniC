## Compiling and Running the Projects

### 1. Clone the repository

```bash
git clone https://github.com/olidbk/MiniC.git
```

### 2. Enter the repository

```bash
cd MiniC
```

### 3. Compile a C project

For example:

```bash
gcc Projects/Easy/calculator.c -o calculator
```

### 4. Run the program

On Linux/macOS:

```bash
./calculator
```

On Windows:

```bash
calculator.exe
```

You can also use another C compiler such as `clang`:

```bash
clang Projects/Easy/calculator.c -o calculator
```

Some projects may require additional compiler flags, libraries, or dependencies. If a project has specific requirements, they will be documented alongside the project.
